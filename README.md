# 🏠 Bsun Mortgage Calculator

### A Free, Browser-Based Mortgage Calculator

A responsive mortgage calculator developed by **Bisan Subba** using HTML, CSS and JavaScript.

Calculate mortgage repayments, explore monthly overpayments, estimate interest savings and visualise your mortgage balance over time.

---

## ✨ Features

- **Mortgage Repayments** — Calculate monthly repayments.
- **Mortgage Overpayments** — Explore additional monthly payments.
- **Interest Savings** — Estimate potential savings.
- **Mortgage Types** — Repayment and interest-only.
- **Deposit Options** — Enter deposits in GBP or percentage.
- **Flexible Mortgage Terms** — Specify years and months.
- **Mortgage Balance Chart** — Visualise outstanding balances.
- **Amortisation Schedule** — View yearly or monthly breakdowns.
- **Reset Function** — Clear all input values and results.
- **Responsive Design** — Suitable for desktop and mobile browsers.

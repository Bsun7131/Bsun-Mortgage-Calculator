Bsun Mortgage Calculator

A free, browser-based mortgage calculator developed by Bisan Subba using HTML, CSS and JavaScript.

Calculate monthly mortgage repayments, explore overpayment scenarios, estimate interest savings and visualise mortgage balances over time.

Features

Repayment and interest-only mortgage calculations
Deposit calculations in GBP or percentage
Flexible mortgage terms in years and months
Optional monthly overpayments
Estimated interest savings and payoff dates
Interactive mortgage balance chart
Yearly and monthly amortisation schedules
Responsive dark-themed interface
No registration required
